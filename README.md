# PTSD 臨床導航

繁體中文互動臨床決策輔助網頁，將安全評估、PTSD診斷條件、共同治療選擇與後續追蹤串成完整流程。供臨床人員教育與決策輔助，不代替醫師診斷或處方。

網站：https://yht5582-source.github.io/PTSD/

## 使用流程

1. **安全與背景**：確認年齡、事件類型、距事件時間、症狀時間及目前安全狀態。自傷意圖、傷人危險、急性精神症狀或嚴重中毒／戒斷優先緊急處置。
2. **診斷評估**：檢查創傷暴露條件A、B/C/D/E症狀群、症狀超過1個月、痛苦／功能影響，以及物質、藥物和身體疾病的解釋。未評估不視為陰性。症狀提示並非經驗證的中文量表。
3. **治療選擇**：先共同討論CPT、PE及EMDR，依偏好、可近性與共病規劃。診斷經醫師確認、偏好與安全檢核完整後，才產生成人藥物劑量參考。
4. **追蹤評估**：記錄正式PCL-5、功能受損、惡夢、足夠療程與依從性、安全及副作用。趨勢圖依實際日期間隔呈現，安全或嚴重不良反應優先於分數改善。

## 臨床保護條件

- PTSD診斷方向需要A、B≥1、C≥1、D≥2、E≥2、時間、功能與排除條件完整；PCL-5高分不能補足缺少的條件。
- 症狀3天至1個月且近期事件者轉急性壓力評估；ASD使用不同規則，不由PTSD症狀群自動診斷。舊創傷伴短期新症狀亦不自動推為ASD。
- 兒少不套用成人PCL-5門檻與劑量。雙相、周產期、重大交互作用及中重度肝病會停止標準用藥建議並提示專科評估。
- Sertraline提供腎肝功能提醒；paroxetine採速放仿單上限；venlafaxine提示CrCl／血液透析調整及血壓風險。不得將三個比較選項合併服用。
- Prazosin僅討論反覆惡夢，不作整體PTSD單方；低血壓／姿勢性症狀不自動推薦。
- 不推薦benzodiazepine或cannabis治療PTSD；既有鎮靜藥不可突然自行停用。
- PCL-5下降10分作反應訊號，不等於緩解；1–2週、2–4週與8–12週為可個別調整的實務追蹤提醒。
- 台灣適應症與健保須依實際TFDA品項、最新給付及院內藥單核對，工具不自動宣稱符合給付。

## 示範病例

內建8例虛構病例：交通事故、事件後兩週、高齡CKD、血液透析低血壓惡夢、自傷計畫、青少年受暴、疑似雙相、高PCL-5但無逃避症狀。載入會清除目前表單及追蹤，避免混用。

## 教學考題與心智圖（2026-11-13新增）

- **20題單選考題**：基礎10題、進階情境10題，包含安全分流、診斷、早期反應、心理治療、透析／肝病用藥、雙相疑慮、兒少及追蹤。
- 完成全部20題後提交，顯示分數、正確答案、逐題解析及原始指引來源。支援未答提示、難度篩選、重新作答與結果匯出。
- 錯題可直接跳到相關心智圖分支複習。作答僅在本頁記憶體保留，切換頁面不丟失，重新整理會清空；不混入臨床評估與追蹤。
- **詳細心智圖**：8個主題、25個分支、75個重點，含來源與臨床流程連結。支援多層展開／收合、全部展開／收合、關鍵字搜尋與無結果提示。
- 直接連結：[考題](https://yht5582-source.github.io/PTSD/#quiz)／[心智圖](https://yht5582-source.github.io/PTSD/#mindmap)。

## 資料及匯出

預設僅保留於本頁記憶體。主動勾選「本機保留評估與追蹤」後才寫入目前瀏覽器localStorage；無資料庫、登入或個案上傳。可匯出文字摘要及UTF-8 BOM的追蹤CSV。

一次管理一份評估，換病人請使用「新評估／清除」。共用電腦請勿保留；勿輸入姓名、病歷號等識別資料。清除網站資料、更換瀏覽器、裝置或使用無痕可能遺失紀錄。匯出檔請妥善保管。

## 維護與部署

純HTML/CSS/JavaScript，無外部字型、套件或API。`index.html`是可直接執行的單檔版本，適合GitHub Pages或本機開啟。原始碼拆為`engine.js`、`learning.js`、`learning-ui.js`、`app.js`及`styles.css`，執行`python3 build.py`重建。

```sh
node tests/engine.test.cjs
node tests/learning.test.cjs
python3 build.py
python3 -m http.server 8765
```

GitHub Pages設定使用`main`分支的根目錄。醫療規則更新後請同步更新查核日期、依據、示範及回歸測試，並驗證桌面與手機主要流程。
